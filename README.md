# Mesa Virtual D&D 5e & Ficha PWA
Uma aplicação web leve, interativa e totalmente orientada a Progressive Web App (PWA) desenvolvida para gerenciar sessões de RPG de mesa (Dungeons & Dragons 5ª Edição). O sistema oferece suporte a multiplayer em tempo real via WebSockets, permitindo que o Mestre (DM) e os jogadores sincronizem fichas, posicionem tokens e explorem mapas interativos diretamente pelo navegador do celular ou computador, sem necessidade de instalações complexas.
Recursos Principais
Multiplayer em Tempo Real: Conexão instantânea via salas com códigos de 4 dígitos utilizando Socket.io.
Ficha de Personagem Completa: Gerenciamento de atributos, testes de resistência, perícias, magias, inventário e barras de vida dinâmicas.
Mapa Tático Interativo: Movimentação de tokens em tempo real, suporte a marcações de pontos de interesse e ferramentas de medição para o Mestre.
Suporte a PWA: Pronto para ser instalado como um aplicativo nativo no celular (com suporte a modo tela cheia e ícone dedicado).
